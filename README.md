# Achados Feed

Landing page para o grupo de ofertas Achados Feed (WhatsApp), preparada para publicação no Render.

## Enviar o projeto completo (1 arquivo)

1. Baixe o ZIP `achados_feed_v2_3_render_pronto.zip` fornecido na conversa do ChatGPT.
2. No repositório GitHub, clique em **Add file → Upload files**.
3. Arraste o **ZIP inteiro** (não descompacte) e clique em **Commit changes**.

Uma automação deste repositório extrairá os arquivos e os organizará automaticamente na raiz. Acompanhe em **Actions → Instalar projeto a partir do ZIP**; a execução deve ficar verde. Se o GitHub solicitar habilitar Actions, faça isso.

### Atenção
- Não envie arquivos `.env` nem senhas. O pacote contém apenas `.env.example`.
- O Render precisará das variáveis `ADMIN_PASSWORD`, `SESSION_SECRET` e de um banco `DATABASE_URL`.
- O plano gratuito serve somente para testes; para anúncios pagos, use hospedagem sem hibernação e banco de dados durável.
- As entradas no WhatsApp não são confirmadas automaticamente: o site contabiliza cliques no convite.
- A página não é afiliada oficialmente à Shopee, Mercado Livre ou WhatsApp.
